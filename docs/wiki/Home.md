# Mira — Wiki del proyecto

**Mira** es una plataforma web de gestión de proyectos Scrum y Kanban: proyectos,
backlog, tablero, roles y trazabilidad de los cambios. Proyecto del ramo
**INF331 — Pruebas de Software** (UTFSM, segundo semestre 2026).
